## Overview

A responsive four-card feature section inspired by the Frontend Mentor design challenge. The layout includes a centered intro, four feature cards, and a mobile-friendly stack that adapts cleanly across screen sizes.

### The challenge

Users should be able to:

- View the optimal layout for the site depending on their device's screen size
- See hover states for interactive elements
- Enjoy a clean, readable, visually balanced card layout

## My process

1. I reviewed the design carefully and mapped out the layout structure.
2. I built the semantic HTML for the heading, intro text, and four cards.
3. I styled the page using CSS, focusing on spacing, borders, shadows, and typography.
4. I used CSS Grid and Flexbox to create the responsive feature-card layout.
5. I tested the layout across smaller and larger screen sizes to ensure readability and balance.
